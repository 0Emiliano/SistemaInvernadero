## 📊 Lo que se implementó

### Stack de Observabilidad Completo

**1. Prometheus** (Métricas)
- ConfigMap con scrape configs
- Alert rules automáticas
- 30 días de retención
- RBAC configurado

**2. Grafana** (Dashboards)
- Datasources: Prometheus, Loki, Jaeger
- UI en puerto 3000 (user: admin, pass: admin123)

**3. Jaeger** (Distributed Tracing)
- All-in-one deployment
- UI en puerto 16686
- Traces de requests HTTP
- Service dependency graph

**4. Loki** (Log Aggregation)
- Log collection desde backend
- LogQL queries
- 30 días retención
- Integrado con Grafana

**5. Backend Actualizado**
- `pom.xml`: Agregadas dependencias Micrometer, Jaeger, Loki, JWT
- `logback-spring.xml`: Configuración para enviar logs a Loki
- `application.properties`: Endpoints de observabilidad
- Micrometer Prometheus Registry
- Micrometer Tracing bridge

**6. Supabase Migration**
- Guía completa para migrar a Supabase (PostgreSQL 15)
- TimescaleDB incluido en Supabase
- Backend manifest actualizado para Supabase
- Credentials management en K8s secrets

## 🚀 Cómo Desplegar

### Stack de Observabilidad
```bash
kubectl apply -f k8s/prometheus.yaml
kubectl apply -f k8s/grafana.yaml
kubectl apply -f k8s/jaeger.yaml
kubectl apply -f k8s/loki.yaml
```

### Supabase + Backend
```bash
# 1. Crear proyecto en supabase.com
# 2. Crear secret con credenciales
kubectl create secret generic supabase-credentials \
  --from-literal=host=your-project.supabase.co \
  --from-literal=port=5432 \
  --from-literal=database=postgres \
  --from-literal=username=postgres \
  --from-literal=password=PASSWORD \
  -n invernadero

# 3. Recompilar backend
docker build -t invernadero-backend:latest ./java-backend

# 4. Desplegar
kubectl apply -f k8s/backend-supabase.yaml
```
