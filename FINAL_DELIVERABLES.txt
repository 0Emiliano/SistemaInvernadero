🚀 QUICK START
───────────────
1. Deploy observability stack:
   kubectl apply -f k8s/{prometheus,grafana,jaeger,loki}.yaml

2. Create Supabase secret:
   kubectl create secret generic supabase-credentials \
     --from-literal=host=project.supabase.co \
     --from-literal=password=PASSWORD -n invernadero

3. Deploy backend:
   docker build -t invernadero-backend:latest ./java-backend
   kubectl apply -f k8s/backend-supabase.yaml

4. Port-forward services:
   kubectl port-forward svc/prometheus-service 9090:9090 &
   kubectl port-forward svc/grafana-service 3001:3000 &
   kubectl port-forward svc/jaeger-service 16686:16686 &

5. Access:
   - Prometheus: http://localhost:9090
   - Grafana: http://localhost:3001 (admin/admin123)
   - Jaeger: http://localhost:16686
